# PRAIN v0.9.2 — Phase-0 Consolidation & Acceptance Gate

**Status: CONSOLIDATED REVIEW PACKAGE — NOT PHASE-0 APPROVED.**

This package consolidates the v0.9.1 schema audit, knowledge-base comparison, claim-semantics proposal, seven-track status, and an explicit Phase-0 acceptance gate. It is specification-only. No runtime, framework, OS, deployment, or production implementation is included.

- `docs/CONSOLIDATION_AND_PHASE0_GATE.md`: integrated findings and release criteria.
- `docs/DECISION_REVIEW_TABLE.md`: existing decisions, proposed decisions, and user decisions kept separate.
- `docs/SCHEMA_FIELD_AUDIT_DEEP.md`: static schema inventory and structural findings.
- `docs/KNOWLEDGE_BASE_ITEM_AUDIT.md`: JSON/HTML data parity and semantic remediation.
- `docs/CLAIM_SEMANTICS_AND_EPISTEMIC_LIFECYCLE.md`: proposed claim model.
- Other crosswalk, traceability, conformance, and versioning materials from v0.9.1.

## Release rule
A release candidate is not a release approval. Phase 0 remains open until blocking design decisions are resolved or explicitly accepted as deferred, required evidence is produced, and the user explicitly approves the closure record. v0.1.0 / Phase 1 remains gated on that approval.
